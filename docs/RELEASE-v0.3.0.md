## 已知边界

doctor 对照显式结构与已声明输入，不理解所有自然语言规则，也不能认证报告真的执行过、批准真实或输入清单完整。证据匹配不是产品 GREEN，人工部署/客户验收字段仍只是记录值。实际产品需要真实测试、受控 CI 及必要审查。

未登记档案、复杂 Markdown 语义、远程链接未被认证；未适配旧格式会报错，不自动迁移。基线按声明文件摘要保守判定变化，可能要求人工确认是否需要重验；不能精确推断所有依赖影响。

协作锁和源复核不是针对任意恶意进程的完整事务。外部代理评测不是 OS 沙箱；同权限程序仍可能访问评分器或其他文件，正式评测应由宿主/容器隔离。公开夹具有过拟合风险，初始化/联调限制题的语义评分仍待人工复核。

客户项目 CI、主分支保护、客户端自动调用和秘密隔离均未由此次安装自动设置。框架自测不能用于宣传模型成功率提升或强弱模型对比结论。
