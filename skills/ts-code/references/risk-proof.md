# 按实际边界选择证据

只检查当前改动的真实影响，证据按并集合并；同一检查可覆盖多项。LIGHT / STANDARD / FULL 表示证据强度，不表示固定测试数量。
权限、金额、历史数据、破坏性公共契约变更采用强化验证；新写/修改生产迁移至少标准设计、强化验证。核心领域变化需要明确身份、归属、不变量与消费者影响分析。

## 权限与身份
在真正执行权限的位置验证允许/拒绝、未认证或失效凭据、所有权/租户替换及提权路径，按实际边界选择。按钮隐藏不证明后端拒绝。
受影响的已有角色、会话和调用入口需回归；客户端/会话连接改变结果时补真实旅程。纯函数演示不能认证整个 HTTP/会话系统。

## 数据、金额与共享契约
数据库语义决定正确性时使用隔离的真实持久化，验证受影响约束、事务、读写一致性、排序/分页、失败不污染及回滚。
金额按影响验证精度、舍入、重复处理、部分失败与适用冲正/退款；金额显示变化与真实扣款分别界定，不连带审计无关支付链路。
共享数据从产生方追到存储/传输及已有消费者；两个各自通过的模拟测试不证明彼此兼容。
破坏性公共接口改变须得到授权并明确版本/过渡或有意拒绝旧调用的行为。历史数据验证真实旧状态、引用保留和预期变化。
版本化导入区分业务身份与表示：JSON 相等、手机号等可变字段不能自行定义唯一身份；覆盖旧新共存、重复/修订记录及下游引用。

## 迁移与真实数据操作
新写或修改生产迁移在隔离的代表性旧数据上验证兼容、引用保留、适用重试/并发与回滚或向前恢复；空库通过不证明旧数据安全。
仅补跑未改动的已有本地迁移：核对本地目标与准确待执行脚本、安全性、备份/恢复点、执行状态、原故障恢复。无需自动全模块审计。
不重置数据、不顺带跑未知迁移；多个迁移关系不清、目标不明、损坏或不安全变换时不可使用简化例外。
生产执行按批准的操作手册，重新确认可变目标及恢复准备；本地通过不授权生产写入，不为了对称而生成破坏性回滚。

## 外部接口
受影响调用验证超时、异常响应、网络失败；适用时覆盖重试上限、限流、幂等、单位/空值映射、分页和凭据刷新。
分别标记模拟契约、脱敏真实响应回放、真实服务联调。人工夹具不证明提供方真实结构；缺凭据不能悄悄用模拟替代要求的联调。
一次联调成功不代表服务整体可靠。测试默认隔离于付费/生产服务，调用前取得相应授权，证据不包含秘密或个人数据。

## 并发
存在竞争时采用可确认重叠的请求/事务/屏障，验证最终持久状态、各请求结果及副作用次数。串行重复不等于竞争测试；仅 sleep 不证明重叠。
选择会破坏当前不变量的交错，例如库存竞争、重复回调、丢失更新、取消与完成竞争。无法可信复现时说明缺口。

## 界面、异步与派生结果
视觉变化需要代表性渲染及标准对应观察；操作变化验证入口、动作、结果及适用错误恢复；保存行为需真实持久路径和刷新证明。
截图不证明数据保存，DOM 断言不证明视觉质量。异步任务入队、上传响应、缓存命中或 HTTP 成功码不单独证明业务完成。
后台任务检查完成/失败、重试、重复和旧结果覆盖；上传检查拒绝边界、处理中断、归属及安全解释；缓存检查失效、隔离、过期；搜索检查空查询、过滤/分页顺序、权限和旧响应覆盖，按受影响项选取。

缺少必要证据则报告当前缺口，不通过扩大措辞、修改档位或宣告“原型”免除底线。
