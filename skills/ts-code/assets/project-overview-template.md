## 1. 目标与本期范围
客户是谁、要解决什么问题、首个可用结果是什么；本期做什么、不做什么、哪些仍是建议或待确认。里程碑只记已约定内容。

先展示可操作的业务结果和实际运行/演示入口，再链接详细证据；技术切片可用接口结果或命令输出，不强制截图或 UI。只描述真实执行，不为客户展示虚构演示。
分别说明开发/验证、客户验收及测试环境/生产部署；没有证据时写未验证，不根据代码存在推断可用。
