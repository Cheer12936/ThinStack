# ThinStack 评估

## v0.3.1 可执行框架

从 [harness/README.md](harness/README.md) 开始。已有七类可运行夹具，新增“本地已有迁移未执行”的优惠券故障；默认裸调用/自主/引导三组，也可加载不可变 Skill 快照做四版本或其他多组比较。`selftest` 使用硬编码正反控制，不调用模型；`run` 需要明确配置实际代理及执行授权。结果包括原始轨迹、起点与最终摘要、范围差异、无依据完成、不必要阻塞、最长耗时及待人工语义复核项。

框架自测通过不等于模型实验已运行，更不等于某个模型或技能有百分之百成功率。保留同一模型配置、项目事实与工具权限，排除全局其他技能污染；隔离评判程序与不可信候选。公开夹具存在过拟合风险，后续应增加留出任务。

本次工具交付记录见 [v0.3.1 说明](../docs/RELEASE-v0.3.1.md)。历史场景中的 NOT_RUN 不因框架自测而改成 PASS。
